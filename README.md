# Intelligent Image Document Analyzer

## Overview

The Intelligent Image Document Analyzer is a Python-based computer vision project designed to extract structured information from invoice images.

The project will use image preprocessing, Optical Character Recognition (OCR), text cleaning, field extraction, and data validation to produce structured JSON output through a FastAPI API.

## Planned Features

- Invoice image upload and validation
- Image preprocessing using OpenCV
- Text extraction using Tesseract OCR
- OCR text cleaning and normalization
- Rule-based invoice field extraction
- Structured output validation using Pydantic
- REST API with interactive Swagger documentation
- Automated testing and extraction-accuracy evaluation

## Technology Stack

- Python
- FastAPI
- OpenCV
- Tesseract OCR
- Pydantic
- pytest
